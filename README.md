# PocketPayslip: Mobile App Developer Salary in India

An interactive landing page for the guide **Mobile App Developer Salary in India: Skills and Career Growth**. Drag the experience slider, pick a platform, stack your skills and watch the estimated yearly package change inside a phone screen.

## What is inside

- A salary simulator that responds to years of experience, platform and extra skills
- A five version career timeline, written like an app changelog
- An app icon shelf with five learning paths for Delhi and NCR learners
- A reading list styled as notifications
- Fully responsive layout, keyboard friendly controls and reduced motion support

## Run it

Open `index.html` in any browser. No build step and no dependencies, apart from two Google Fonts that fall back to system fonts when offline.

## Publish with GitHub Pages

1. Push the files to the repository root.
2. Open Settings, then Pages.
3. Choose the main branch and the root folder, then save.
4. Your page will be live at `https://your-username.github.io/your-repo-name/`.

## Note

Salary figures are indicative ranges based on commonly reported market patterns and are meant for learning. Actual offers vary with company, city, skills and negotiation.
